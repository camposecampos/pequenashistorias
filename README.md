# Pequenas Histórias, Grandes Sementes
Página de apresentação do ebook da Campos & Campos. Site estático, responsivo, sem dependências de build.

## Publicação no GitHub Pages
Crie o repositório `pequenashistorias` na conta `camposecampos`, envie os arquivos à branch `main` e, em Settings → Pages, escolha GitHub Actions. O workflow de publicação já está incluído.

## Checkout Hotmart
Em `config.js`, preencha `checkoutUrl` com o link real HTTPS `pay.hotmart.com` deste produto. Enquanto vazio, a página mostra “Vendas em breve” e não exibe botão de compra. Não há preço configurado.

## Conteúdo
Apenas a primeira história é apresentada como amostra. O PDF completo pago não está neste repositório. Imagens otimizadas em JPEG; diálogo acessível para amostra; sem trackers ou formulários. Confirmar checkout, preço, suporte e condições de compra antes de iniciar anúncios.
